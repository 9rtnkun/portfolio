## About

A single-page website that gathers my skills, projects, and contact details in one place. I've always loved games and anime, and seeing new innovations inspired me to start creating things myself. Now I'm learning and building step by step.

## Features

- Single-page layout with Projects, Skills, and Contact sections
- Dark theme with a clean, modern design
- Thai / English text switching (`data-i18n`)
- Project cards with screenshots linking to each GitHub repository
- Skill cards grouped by topic
- Responsive layout for desktop and mobile
- Hand-written HTML, CSS, and JavaScript — no framework
